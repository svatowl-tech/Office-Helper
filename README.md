# Офисный помощник

**Офисный помощник** — полностью автономное приложение для повседневной работы с документами, сканами, аудио/видеозаписями и большими архивами на русском языке. Работает **без интернета, без установки и без прав администратора** на обычном офисном компьютере (видеокарта не требуется). Все данные обрабатываются строго локально и никуда не передаются.

---

## Пять инструментов в одном окне

На главном экране модули расположены в компактной сетке (**3 инструмента сверху и 2 широких снизу**). Каждый инструмент работает как полностью самостоятельно, так и в связке с остальными в один клик.

### `[ 01 ]` Исправить язык
- Проверяет орфографию, пунктуацию, падежное управление, типографику и формулировки (длинные тексты автоматически разбиваются на чанки под малые локальные CPU-модели и собираются обратно без потерь).
- **Сохраняет исходное оформление**: шрифты, таблицы, колонтитулы, макеты слайдов и формулы в электронных таблицах остаются нетронутыми.
- **Какой формат на входе — такой и на выходе**: загрузили `.docx` — скачиваете исправленный `.docx`; загрузили `.odt`, `.ods` или `.xodt` — получаете тот же формат.
- **Отдельная сводка исправлений для ручной перепроверки**: помимо чистого исправленного документа формирует отдельный файл `Сводка_исправлений_<Имя>.docx` (и встроенную таблицу **«Сводка»**) с точным перечнем каждой правки (`Место в документе` · `Категория` · `Было` → `Стало` · `Пояснение` · контекст абзаца).

### `[ 02 ]` Распознать текст
- Локальное распознавание **русского и английского текста**, сложных таблиц (счета, акты, ведомости, спецификации) и графики (**логотипы, печати, схемы, чертежи**) из файлов **PDF, PNG, JPG, BMP, TIFF, WebP** на базе **MuPDF + RapidOCR ONNX** (с резервным оффлайн-Tesseract).
- Сохраняет исходный текст и реквизиты **дословно без автоискажений**, а найденные логотипы, печати и чертежи вставляет на исходные места.
- Выдаёт готовый редактируемый документ **Word (`.docx`)** или таблицу **Excel (`.xlsx`)** на выбор.

### `[ 03 ]` Надиктовать голосом и расшифровать запись совещания
- **Голосовая диктовка**: распознаёт русскую речь полностью оффлайн через локальный **Whisper**, поддерживает **паузу и продолжение** записи, автоматически расставляет пунктуацию и формирует готовый `.docx`.
- **Загрузка записи совещания**: принимает аудиофайлы с диктофона (`MP3`, `WAV`, `M4A`, `AAC`, `OGG`, `OPUS`, `FLAC`, `WMA`, `AMR`, `3GP`, `AIFF`) и видеозаписи (`MP4`, `MKV`, `MOV`, `AVI`, `WEBM`, `WMV`, `MPEG`, `TS`), локально извлекает аудиодорожку (FFmpeg), расшифровывает в текст с возможностью редактирования, копирования и скачивания в **Word (`.docx`)** и **TXT**.

### `[ 04 ]` Деловой стиль
- Комбинированный ввод в одном рабочем окне: можно **написать/вставить текст**, **надиктовать голосом прямо в поле ввода** или **загрузить документ/скан/аудиозапись** для немедленной обработки.
- Сохраняет основную мысль и смысл сказанного, преобразуя неформальные, резкие или разговорные формулировки в **вежливый официальный деловой стиль**, готовый к отправке.
- Результат можно отредактировать на месте, дополнительно проверить орфографию, скопировать одним кликом или скачать в **Word (`.docx`)**.

### `[ 05 ]` Работа с документом (алгоритмический Харнес)
- Специальный модуль для работы с **большими документами** (десятки и сотни страниц) и **тематическими подборками файлов**, спроектированный под малые локальные LLM (1.5B / 95M), которые не вмещают целый файл в контекст.
- Всю тяжёлую работу выполняет **алгоритмический Харнес** на бэкенде, а в локальную модель передаётся только компактный проверенный пакет фактов (≤ 1600 символов):
  - **Два режима доступа к файлам**: загрузка документов в текущую сессию (в оперативной памяти) **или прямой доступ к папке/файлу на диске в режиме чтения без копирования** (путь можно указать в боковой панели или написать прямо в тексте запроса, например: *«Найди в папке D:\Договоры\2026 все суммы и реквизиты»*).
  - **Поиск ответов со ссылками** (BM25 + русско-английский стемминг): точные цитаты с указанием файла, страницы/листа и раздела.
  - **Извлечение структурированных данных**: суммы, даты, номера договоров/актов/счетов, реквизиты (`ИНН`, `КПП`, `ОГРН/ОГРНИП`, `БИК`, `р/с`, `к/с`, e-mail, телефоны) и таблицы.
  - **Автоматическое оглавление и краткая сводка** больших файлов (клик по пункту оглавления сразу открывает разбор нужного раздела).
  - **Сборка нового Word (`.docx`) или Excel (`.xlsx`)** из найденных фрагментов, реквизитов и таблиц — голосовой/текстовой командой или кнопкой под ответом.

## Взаимосвязь инструментов (единая цепочка)

Каждый результат в нижней панели снабжён компактной кнопкой **«Далее →»**, позволяющей без ручного пересохранения передать файл в следующий инструмент. Примеры типовых сценариев:

- `Скан PDF [ 02 ]` → **`[ 01 ]` Исправить язык** → **`[ 05 ]` Работа с документом** (извлечь суммы и собрать сводку в Excel).
- `Запись совещания [ 03 ]` → **`[ 04 ]` Деловой стиль** (оформить официальное письмо/протокол) → **`[ 01 ]` Исправить язык**.
- `Выборка из архива [ 05 ]` → **`[ 04 ]` Деловой стиль** (превратить найденные факты в вежливый ответ контрагенту) → скачать `.docx`.

## Поддерживаемые форматы

| Задача | Поддерживаемые форматы |
| :--- | :--- |
| **Microsoft Office** | `.docx`, `.xlsx`, `.pptx`, `.doc`, `.xls`, `.ppt` |
| **LibreOffice / OpenOffice** | `.odt`, `.ods`, `.odp` |
| **МойОфис** | `.xodt`, `.xods` |
| **Текстовые и табличные** | `.rtf`, `.txt`, `.md`, `.csv` |
| **Распознавание (OCR)** | `.pdf`, `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tif`, `.tiff`, `.webp` → `.docx` / `.xlsx` |
| **Голос и записи совещаний** | Микрофон, `MP3`, `WAV`, `M4A`, `AAC`, `OGG`, `OPUS`, `FLAC`, `WMA`, `AMR`, `3GP`, `AIFF`, `MP4`, `MKV`, `MOV`, `AVI`, `WEBM`, `WMV`, `MPEG`, `TS` → текст + `.docx` / `.txt` |
| **Деловой стиль** | Ручной ввод, диктовка в поле, любой офисный документ, скан или аудио/видеозапись → текст + `.docx` |
| **Работа с документом (Харнес)** | Все офисные форматы, PDF (цифровые и сканы), изображения, локальные папки и файлы напрямую с диска без копирования → ответы с цитатами + `.docx` / `.xlsx` |

## Где скачать программу

Готовые сборки находятся в разделе **Releases** (в правой колонке страницы репозитория на GitHub):

- **`office-assistant-ru-portable-airgap.zip`** — полный портативный пакет для **Windows (7 / 8 / 10 / 11)** и **Linux** (включает локальные движки и модели, ничего докачивать не нужно).
- **`office-assistant-ru-astra-linux-portable.tar.gz`** — полный пакет в формате `.tar.gz` для **Astra Linux** и других Linux-систем.
- **`Офисный-Помощник-Автономный.html`** — облегчённая **однофайловая версия**, открывается двойным кликом в браузере, если на рабочем ПК запрещён запуск `.exe` / `.run`.

## Как запустить и пользоваться

### Запуск на Windows (7 / 8 / 10 / 11)
1. Скачайте **`office-assistant-ru-portable-airgap.zip`** и распакуйте в любую папку (например, на Рабочий стол или флешку).
2. Запустите двойным кликом **`Офисный-Помощник.exe`** — сервер запустится локально и автоматически откроет интерфейс в браузере (`cmd.exe` и `.bat`-скрипты не требуются).

### Запуск на Linux / Astra Linux
1. Скачайте **`office-assistant-ru-astra-linux-portable.tar.gz`** (или `.zip`) и распакуйте архив.
2. Запустите **`Офисный-Помощник-AstraLinux.run`** (или `start-astra-linux.sh`).

### Запуск без исполняемых файлов (любая ОС)
1. Скачайте **`Офисный-Помощник-Автономный.html`**.
2. Откройте файл двойным кликом в браузере (Chrome, Firefox, Яндекс.Браузер, Chromium-Gost, Edge).

### Быстрый старт по модулям
1. **`[ 01 ]` Исправить язык**: нажмите **«Выбрать файл»** → дождитесь завершения → скачайте готовый документ внизу или нажмите **«Далее →»**.
2. **`[ 02 ]` Распознать текст**: выберите **DOCX** или **XLSX** → нажмите **«Загрузить PDF»** → скачайте точную копию с таблицами и графикой.
3. **`[ 03 ]` Надиктовать голосом**: нажмите **«Начать запись»** для диктовки с микрофона либо **«Загрузить запись совещания»** для аудио/видеофайла.
4. **`[ 04 ]` Деловой стиль**: введите текст, нажмите **«Диктовать»** (речь вставляется прямо в поле) или **«Документ»** (мгновенная обработка файла) → нажмите **«Преобразовать»**.
5. **`[ 05 ]` Работа с документом**: загрузите файлы в сессию, подключите локальную папку/файл на диске без копирования или сразу напишите вопрос с путём к папке → получайте ответы со ссылками на страницы, таблицы, реквизиты и собирайте новые `.docx` / `.xlsx`.

## Системные требования

- **Операционная система:**
  - Windows 7 SP1 / 8 / 8.1 / 10 / 11 (64-bit) — оптимальный бинарник движка выбирается автоматически.
  - Linux x86_64 (Astra Linux SE 1.6 / 1.7, Debian 10+, Ubuntu, ALT Linux, РЕД ОС и др.) — статические бинарники без установки системных зависимостей.
- **Процессор:** любой 64-разрядный CPU с `SSE4.2` (при наличии `AVX2` ускоренный режим включается автоматически).
- **Оперативная память:** от 4 ГБ ОЗУ (рекомендуется 8 ГБ).
- **Видеокарта:** не требуется (все вычисления идут на CPU).
- **Интернет:** не требуется после скачивания архива.

## Переменные окружения (`.env.example`)

| Переменная | По умолчанию | Назначение |
| :--- | :--- | :--- |
| `PORT` / `HOST` | `3000` / `0.0.0.0` | Порт и сетевой интерфейс локального сервера |
| `LOCAL_MODELS_DIR` | `./models` | Папка с локальными весами моделей (GGUF / ONNX / Whisper) |
| `LOCAL_LLAMA_SERVER_URL` | `http://127.0.0.1:8080` | Адрес локального `llama-server` (при отсутствии работает детерминированное ядро) |
| `LOCAL_TESSDATA_DIR` | `./tessdata` | Локальные словари Tesseract OCR (`rus.traineddata`, `eng.traineddata`) |
| `HARNESS_CHUNK_MAX_CHARS` | `480` | Максимальный размер чанка текста под малое окно контекста |
| `FFMPEG_PATH` / `FFPROBE_PATH` | автопоиск | Опциональные пути к локальным бинарникам FFmpeg/FFprobe для видео и аудио совещаний |

## Для разработчиков: локальная сборка из исходников

```bash
npm install
npm run lint
npm run build
```

Запуск в режиме разработки (порт `3000`):

```bash
npm run dev
```

Запуск собранного портативного сервера:

```bash
npm run start:portable
```

Автоматическая сборка всех портативных пакетов (Windows + Linux + модели + однофайловый HTML) и публикация в **GitHub Releases** настроена в `.github/workflows/build-airgap-bundle.yml`.
