# Офисный помощник

**Офисный помощник** — полностью автономное приложение для повседневной работы с документами на русском языке. Работает **без интернета, без установки и без прав администратора** на обычном офисном компьютере (видеокарта не требуется). Все данные обрабатываются строго локально на вашем компьютере и никуда не передаются.

---

## Для чего нужна программа

Приложение объединяет три повседневные офисные задачи в одном простом окне:

1. **Исправить русский язык в документе**
   - Проверяет орфографию, пунктуацию, падежное управление, типографику и формулировки делового стиля (включая длинные документы — текст автоматически разбивается на фрагменты и собирается обратно без потерь).
   - **Сохраняет исходное оформление**: шрифты, таблицы, колонтитулы, макеты слайдов и формулы в электронных таблицах остаются нетронутыми.
   - **Какой формат на входе — такой и на выходе**: загрузили `.docx` — скачиваете исправленный `.docx`; загрузили `.odt` или `.ods` — получаете `.odt` или `.ods`.

2. **Распознать PDF или картинку (скан / фото)**
   - Точно извлекает **русский и английский текст**, сложные таблицы (счета, акты, спецификации) и графику (**логотипы, печати, схемы, чертежи**) из файлов **PDF, PNG, JPG, BMP, TIFF, WebP** на базе локальных движков **MuPDF + RapidOCR ONNX**.
   - Сохраняет исходный текст и реквизиты **дословно без автоискажений**, а найденные логотипы, печати и чертежи вставляет на исходные места.
   - Выдаёт готовый редактируемый документ **Word (`.docx`)** или таблицу **Excel (`.xlsx`)** на выбор.

3. **Надиктовать текст голосом (локальный Whisper)**
   - Распознаёт русскую речь полностью оффлайн на процессоре (без облачных сервисов).
   - Поддерживает **паузу и продолжение** записи (можно прерваться и продолжить надиктовку с того же места).
   - После завершения автоматически расставляет пунктуацию, прогоняет весь текст через систему исправления и выдаёт готовый документ **Word (`.docx`)**.

## Поддерживаемые форматы

| Задача | Поддерживаемые форматы |
| :--- | :--- |
| **Microsoft Office** | `.docx`, `.xlsx`, `.pptx`, `.doc`, `.xls`, `.ppt` |
| **LibreOffice / OpenOffice** | `.odt`, `.ods`, `.odp` |
| **МойОфис** | `.xodt`, `.xods` |
| **Универсальные текстовые** | `.rtf`, `.txt`, `.md` |
| **Распознавание (OCR)** | `.pdf`, `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tif`, `.tiff`, `.webp` → `.docx` / `.xlsx` |
| **Голосовая надиктовка** | Микрофон → локальный Whisper → `.docx` |

## Где скачать программу

Готовые сборки находятся в разделе **Releases** (блок **Releases** в правой колонке страницы репозитория на GitHub).

Выберите подходящий файл из последнего релиза:

- **`office-assistant-ru-portable-airgap.zip`** — полный портативный пакет для **Windows (7 / 8 / 10 / 11)** и **Linux** (включает все локальные движки и модели, ничего докачивать не нужно).
- **`office-assistant-ru-astra-linux-portable.tar.gz`** — тот же полный пакет в формате `.tar.gz` для **Astra Linux** и других Linux-систем.
- **`Офисный-Помощник-Автономный.html`** — облегчённая **однофайловая версия**: открывается двойным кликом прямо в любом браузере, если на рабочем ПК действуют строгие политики безопасности и запрещён запуск `.exe` / `.run` файлов.

## Как запустить и пользоваться

### Запуск на Windows (7 / 8 / 10 / 11)
1. Скачайте **`office-assistant-ru-portable-airgap.zip`** и распакуйте архив в любую удобную папку (например, на Рабочий стол или флешку).
2. Запустите двойным кликом **`Офисный-Помощник.exe`** (приложение само запустит локальный сервер и откроет интерфейс в браузере; командная строка `cmd.exe` и `.bat`-скрипты не требуются).

### Запуск на Linux / Astra Linux
1. Скачайте **`office-assistant-ru-astra-linux-portable.tar.gz`** (или `.zip`) и распакуйте архив.
2. Запустите **`Офисный-Помощник-AstraLinux.run`** (или `start-astra-linux.sh`).

### Запуск без исполняемых файлов (любая ОС)
1. Скачайте один файл **`Офисный-Помощник-Автономный.html`**.
2. Откройте его двойным кликом в браузере (Chrome, Firefox, Яндекс.Браузер, Chromium-Gost, Edge).

### Как работать в программе
1. **Проверка документа**: нажмите **«Исправить русский язык»** → выберите файл → дождитесь полосы прогресса → нажмите **«Скачать»** в нижней панели.
2. **Распознавание сканов и PDF**: выберите нужный формат результата (**Word** или **Excel**) → нажмите **«Распознать PDF (картинку)»** → скачайте готовый файл внизу экрана.
3. **Голосовая надиктовка**: нажмите **«Надиктовать текст»** (загорится красный индикатор записи) → продиктуйте текст → при необходимости нажмите **«На паузу»** / **«Продолжить»** → нажмите **«Завершить»** → скачайте исправленный документ Word (`.docx`) из нижней панели.

## Системные требования

- **Операционная система:**
  - Windows 7 SP1 / 8 / 8.1 / 10 / 11 (64-bit) — нужная версия движка выбирается автоматически.
  - Linux x86_64 (Astra Linux SE 1.6 / 1.7, Debian 10+, Ubuntu, ALT Linux, РЕД ОС и др.) — бинарники собраны статически и не требуют установки системных библиотек.
- **Процессор:** любой 64-разрядный процессор с поддержкой `SSE4.2` (при наличии `AVX2` автоматически включается ускоренный режим).
- **Оперативная память:** от 4 ГБ ОЗУ (рекомендуется 8 ГБ для комфортной работы локальных моделей).
- **Видеокарта:** не требуется (все вычисления идут на CPU).
- **Интернет:** не требуется после скачивания архива.

## Для разработчиков: локальная сборка из исходников

```bash
npm install
npm run lint
npm run build
```

Запуск в режиме разработки (порт `3000`):

```bash
npm run dev
```

Автоматическая сборка всех портативных пакетов (Windows + Linux + модели + однофайловый HTML) и публикация в **GitHub Releases** настроена в `.github/workflows/build-airgap-bundle.yml`.
